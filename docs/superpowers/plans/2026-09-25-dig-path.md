# Dig Path Implementation Plan

> **For agentic workers:** execute task-by-task with TDD (failing test → code → green → commit).

**Goal:** Player picks a map cell → agent previews and (after confirm) digs a min-time chain of
occupied cells to it, re-planning when the map changes. **Spec:** `docs/superpowers/specs/2026-09-25-dig-path-design.md`

## Global Constraints
- Map 600×600, `index = y*600 + x`, 4-neighbour adjacency only.
- Never send a game command during preview. Only the farm group digs. `max_loss` always applies.
- Enemy buffer default 2 (setting `dig_enemy_buffer`), forts every >7 cells, prefer land `lv == 1`.
- Game data (`maps_*.json`) is extracted from the user's APK, gitignored, never shipped.

### Task 1: World map data
- `gamedata.extract_config_tables` also writes `tmp/json/maps/*` → `<out>/maps_<n>.json` (list of landIds).
- `nta_agent/execution/worldmap.py`: `WorldMap(maps: dict[str, list[int]], land_rows)`, `WorldMap.load(config_dir)`,
  `detect(owned) -> str` (map with most owned cells on `occupy==1` land), `land(idx) -> dict`, `passable(idx)`, `lv(idx)`.
- Tests: extraction writes maps; detect picks the matching map; passable/lv.

### Task 2: Battle duration from the sim
- `tools/battlesim/reinforce.js` + `forecast.js` results gain `frames` (engine frames simulated) and
  `durationS` (= frames / fps). Python `BattlePrediction` gets optional `duration_s`.
- Tests: JS golden still pass; forecast result has positive durationS.

### Task 3: Pure planner `dig_planner.py`
- `plan_path(owned, target, step_cost, blocked, enemy, buffer, penalty_s, margin) -> Plan`
  (Dijkstra; `reason` ok / no_path / blocked_by_hard), `retarget(...)`, `place_forts(path, nodes, lv_of, every=7)`,
  `enemy_distance_map(enemy, cells)`.
- Tests per spec list.

### Task 4: `dig_cost.py` — `CellCost`
- `march_ms(dist, speed, cd_pct=0)` (engine formula); `CellCost(predict_fn, world, main_index, max_loss, speed)`
  with memo `(landId, attrLv)`; `cost(idx) -> float | None`; fallback rough estimate by lv when predict raises.

### Task 5: `DigService`
- Files: `cfg.dig_request_path` (`dig_request.json`), `cfg.dig_state_path` (`dig.json`).
- States previewing/preview/active/waiting/done/failed/cancelled; replan throttle; retarget; fort enqueue once;
  `next_target()`, `report_hard(idx)`. Scan via injected `scan_fn(focus_chunks)`.
- Wire in `runner.py` (tick in services; `OccupyCell.dig_source`, `dig_hard_sink`).

### Task 6: `OccupyCell._dig_select`
- Priority: defense → dig → expansion → farm. Only the dig cell; farm group; `max_loss`. Emits `dig_step`.

### Task 7: Dashboard
- `server.py`: `read_dig`, `request_dig`, `confirm_dig`, `cancel_dig` + routes; setting `dig_enemy_buffer`.
- `TerritoryPanel.js`: ⛏ button in cell popup, path overlay, status card with confirm/cancel.

### Task 8: Verify + docs
- Full suite + JS tests; live **preview only** on the real map (no confirm); README feature blurb; memory.
