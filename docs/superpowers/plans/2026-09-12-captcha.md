# Captcha Auto-Handling (Chặng 2D) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Detect the anti-cheat captcha (`ecode.500221`) and auto-solve it deterministically from `antiCheat.json`, so the autonomous loop keeps running unattended.

**Architecture:** A pure `solve_answer` + `CaptchaSolver` (`execution/captcha.py`), two thin `Actions` methods, detection at the `RuleEngine.tick` boundary (raise `CaptchaRequired`), solving in `Agent.tick`, and wiring in the runner (reusing the loaded `GameConfig`).

**Tech Stack:** Python 3.12 stdlib, pytest, ruff. Venv at `.venv`.

**Spec:** `docs/superpowers/specs/2026-09-12-captcha-design.md`

## Global Constraints

- Python 3.12; venv runs: `.venv/Scripts/python.exe -m pytest -q`, `.venv/Scripts/python.exe -m ruff check nta_agent tests`. Ruff clean.
- **Trigger:** action reply error containing `ecode.500221`; `GameClient.request` raises `ApiError("<route>: <error>")`, so detect by substring `"ecode.500221"` in `str(e)`.
- **Question:** `game/HD_GetAntiCheatQuestion{}` → `{item: str ("item_N"), options: int[], surplusTime}`.
- **Answer:** correct option = the `antiCheat.json` row (by option id) with `item_<N> == 1`; submit `game/HD_AntiCheatAnswer{answer: int}` → `{rst, wrongCount, notPassCount, surplusTime}`.
- Auto-solve in-process (no vision, no human). A wrong answer just re-challenges next tick — one solve attempt per tick, never a tight loop.
- Reuse `GameConfig` (`config.table("antiCheat")` → `{id: row}`).

```python
# nta_agent/execution/captcha.py
"""Detect + auto-solve the anti-cheat captcha (deterministic from antiCheat.json)."""
from __future__ import annotations

ANTI_CHEAT_ECODE = "ecode.500221"


class CaptchaRequired(Exception):
    """An action hit the anti-cheat captcha (ecode.500221)."""


def solve_answer(item: str, options: list[int], config) -> int:
    """The option id whose antiCheat row has item_<N> == 1; options[0] fallback."""
    try:
        n = int(str(item).split("item_")[1])
    except (IndexError, ValueError):
        return options[0] if options else 0
    table = config.table("antiCheat")
    key = f"item_{n}"
    for opt in options:
        row = table.get(opt) or {}
        if row.get(key) == 1:
            return opt
    return options[0] if options else 0


class CaptchaSolver:
    def __init__(self, actions, config):
        self.actions = actions
        self.config = config

    def solve(self) -> dict:
        q = self.actions.get_anticheat_question()
        answer = solve_answer(q.get("item", ""), q.get("options", []) or [], self.config)
        return self.actions.answer_anticheat(answer)
```

```python
    def __init__(self, rst=True):
        self.rst = rst
        self.calls = 0

        self.calls += 1
        return {"rst": self.rst, "wrongCount": 0}


def _agent(engine, **kw):
```
